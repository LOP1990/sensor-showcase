Acesso para salvar

O painel grava a configuração no repositório do GitHub com um token seu. O token fica guardado só neste navegador.

Como criar o token (2 minutos)
  1. GitHub → foto do perfil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nome: painel-showcase; expiração: 1 ano; Repository access: Only select repositories → sensor-showcase.
  3. Permissions → Repository permissions → Contents: Read and write. Generate e cole aqui.
